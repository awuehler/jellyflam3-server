# JellyFlam3 — Roku Channel Store listing pages

Public copy for the Roku Developer Dashboard (**Privacy and terms** + **Support information**). These pages describe the **JellyFlam3** VoD channel (and, where noted, the separate **JellyFlam3 Dreams** screensaver). They are not a substitute for legal advice.

After they are on `master`, paste these HTTPS URLs into the dashboard (GitHub-rendered markdown is acceptable):

| Dashboard field | URL |
|---|---|
| Privacy policy | https://github.com/awuehler/jellyflam3-server/blob/master/docs/roku-store/PRIVACY_POLICY.md |
| Terms and conditions | https://github.com/awuehler/jellyflam3-server/blob/master/docs/roku-store/TERMS_OF_USE.md |
| Customer support / preferred URL | https://github.com/awuehler/jellyflam3-server/blob/master/docs/roku-store/SUPPORT.md |
| Learn more | https://github.com/awuehler/jellyflam3-server |

**Email and phone** are not published in this repo. Enter the Roku developer-account email and phone on the Support Information page (Roku requires both). Public end-user support is GitHub Issues, as stated on the [support page](SUPPORT.md).

See [Roku app publishing](https://developer.roku.com/dev/docs/channel-publishing-guide) (Privacy and terms; customer support URL, email, and phone).
